# X, CX, CCX and HH: Clément translation experiment

This development translates the existing presentation in
[`CCX+HH-TwoLevel`](../CCX+HH-TwoLevel/) into circuit relations, following
the encode/decode and subgroup steps in
[`Real-Clifford+CH`](../Real-Clifford+CH/). It does not use a Coxeter
presentation or the method of arXiv:2407.11152.

The general-width completeness theorem is **not yet established**.
The current concrete translation is on two wires. The all-width encoder
and shared translation lemmas are intended to support the next stages.

## Conventions and encoding

`Syntactics.agda` uses `Circuit.Base` with exactly `X`, `CX`, `CCX`, and
`HH = H tensor H`. Wire 0 is the least significant basis bit. A primitive
controlled gate targets its bottom wire; its controls occupy the following
wires. Wire permutations are derived circuits, not additional generators.
Words are read in matrix-product order, and equality includes global sign.

`Encoding.agda` encodes the classical gates as disjoint products of
two-level exchanges and `HH` as disjoint four-level `K` blocks. It defines
the compiler at every width. `check_encoding.py` compares these blocks with
independent tensor/basis semantics at all placements through a selected
finite width. A symbolic-width semantic preservation proof remains open.

## The two-wire translation

The ambient group presented by Table 1 on four levels has 1152 elements.
The circuit subgroup generated by `X0, X1, CX10, HH01` has 384 elements.
Consequently a decoder for **every ambient generator on the same wires**
would be incorrect. Instead, the translation tracks three right cosets.

`scripts/two_qubit_schreier.py` constructs and verifies the table

```
representative(c) * auxiliary-generator
  = encode(output(c, generator)) * representative(next(c, generator)).
```

There are 11 auxiliary generators and 33 table entries. The source has
58 Table 1 axiom instances at dimension four. Translating each at all
three states gives 174 circuit equations; four generator recovery
equations bring the total to **178**. Both sides use only the requested
circuit gates. They are stored explicitly in `two_qubit_schreier.json`,
together with the table, representatives and gate conventions.

The generator verifies every source instance, every factorization, every
output equation, and recovery of all 384 subgroup elements using exact
integer arithmetic. The completeness argument is the stateful
back-and-forth argument: translate an auxiliary derivation at its running
coset, then use recovery to return to the original circuits. The relations
are not selected by treating arbitrary matrix equality as an axiom.

`Schreier.agda` formalizes that argument for a supplied coset table;
`TwoQubit/Table.agda` supplies this three-state table and its endpoint
proofs. `TwoQubit/Soundness.agda` proves all 33 factorizations, and
`TwoQubit/Semantics.agda` verifies the encoding against independent gate
matrices. **`TwoQubit/Presentation.agda` proves soundness and completeness
of the 178 equations for ordinary two-wire circuit matrices, with no
hypotheses.** The JSON is a readable computational artifact alongside
these kernel-checked proofs.

## Shared proofs and remaining work

- `OneQubit.agda` proves that `XX = 1` is sound and complete on one wire.
- `Translation.agda` is the direct Clément translation used by `CCX+H`:
  decode the auxiliary axioms and add generator recovery equations.
- `Schreier.agda` gives the corresponding stateful subgroup translation,
  with explicit soundness obligations for the table factorizations.
- `check_subgroup.py` verifies a three-wire obstruction: all circuit
  generators preserve a particular finite set of 240 vectors, but a
  one-level sign does not. Thus the full eight-level Table 1 presentation
  cannot simply be decoded generator by generator on three wires. The
  vectors span the space, so the subgroup acts faithfully on a finite
  set and is finite. The ambient word `K[0123] K[3456]` has trace 1/4
  and hence infinite order: a finite-order rational matrix has integral
  trace. The circuit subgroup therefore has infinite index in this
  ambient group; a finite coset table from the full source will not
  suffice on three wires.
- From four wires onward every primitive circuit gate has determinant
  +1, while individual auxiliary signs and exchanges have determinant
  -1. A suitable auxiliary subgroup presentation is required there too.

The next step is that subgroup presentation and a decoder at general
width, followed by decoded-relation and generator-recovery proofs. The
178 two-wire equations do not constitute an all-width circuit calculus.

## Reproduction

From the repository root, with Agda 2.8.0, standard-library 2.4, and the
checked-out EucDomain submodule registered:

```sh
agda Examples/Groups/CCX+HH/Encoding.agda
agda Examples/Groups/CCX+HH/OneQubit.agda
agda Examples/Groups/CCX+HH/Translation.agda
agda Examples/Groups/CCX+HH/Schreier.agda
agda Examples/Groups/CCX+HH/TwoQubit/Presentation.agda
python3 -B Examples/Groups/CCX+HH/check_encoding.py --max-width 6
python3 -B Examples/Groups/CCX+HH/check_subgroup.py
python3 -B Examples/Groups/CCX+HH/scripts/two_qubit_schreier.py --check Examples/Groups/CCX+HH/two_qubit_schreier.json
```

`scripts/exact_matrices.py` provides the shared exact arithmetic and
optional small-group diagnostics. It does not supply another presentation
method. Generated Agda proofs use ordinary proof terms and must pass the
Agda kernel; there are no postulates or admitted holes.
