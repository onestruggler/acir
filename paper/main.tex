% Inline Agda identifier, in the sans-serif face agda.sty uses for code
% (uncoloured: prose mentions carry no kind information).  Deliberately
% NOT \lstinline (fragile inside macro arguments, tables, and math);
% Unicode in the argument is handled by the \DeclareUnicodeCharacter
% block in agda-style.sty.  \mbox makes it usable in both text and math.
\newcommand{\aid}[1]{\mbox{\textsf{\small #1}}}
% The same for an identifier used as an infix operator or relation: in
% math mode it gets the spacing of a binary operator / relation, so that
% $c \aidop{•} c'$ is set like c • c' rather than c•c'.
\newcommand{\aidop}[1]{\ifmmode\mathbin{\aid{#1}}\else\aid{#1}\fi}
\newcommand{\aidrel}[1]{\ifmmode\mathrel{\aid{#1}}\else\aid{#1}\fi}

\section*{Disclosure of Use of AI in Research}
The authors wrote all of the code except for one major module that combines
the factor presentations of a non-split group extension and some auxiliary
code concerning semantics. We used Claude Opus 4.8 to assist with coding,
literature review, and the writing and editing of the paper.

\section*{Data Availability Statement}
The artifact, version \texttt{popl-revision2}, is available on Zenodo at
\url{https://doi.org/10.5281/zenodo.23636192}.  It contains the Agda
sources, which typecheck with Agda~2.8 and standard library~2.4 as its
\texttt{README.md} describes, and a hyperlinked HTML rendering of
\texttt{MainTheorems.agda} and its imports (\texttt{html/index.html}) for
browsing without Agda.
